###  Project Overview: 
The Vehicle Registration System is an Assembly program designed to manage vehicle records efficiently using modular programming techniques. It provides an interactive menu-driven interface where users can perform common database operations such as adding, deleting, searching, and displaying vehicle records.  
###  Core Features:
* Add Vehicle – Register a new vehicle with Owner Name and Plate Number  
* Delete Vehicle  By Plate Number  All vehicles by Owner Name
* Search Vehicle  By Plate Number  By Owner Name  Display Vehicles  Display all registered vehicles
* Display all vehicles belonging to a specific owner  
###  Key Concepts Demonstrated  
* Modular programming in Assembly
*  Menu-driven user interface
*  Data management using string and memory operations
*  Input validation and error handling
*  Efficient looping and conditional logic
